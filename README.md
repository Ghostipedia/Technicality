Technicality is a continuation and revival of Minimalist Machines by Pyrolusite for GT:CEU As they have been inactive since 2020 and have stopped supporting their project.

This pack was explicitly made to modify textures for the mod "GregTech:Community Edition Unofficial" This pack as it stands changes textures for the vast majority machines, ingots, fluids, and other miscellaneous items. Please Refer to the images tab for a visual overview. As it stands right now, this does not affect vanilla textures.

Eventually a total UI Overhaul is planned that will coalesce Vanilla, JEI and CEU overlays into the same style.

Some materialSets and metaItems from Zedtech have also been used in place of the originals

While this project is simply a revival & remix for now, it will eventually grow to fully encompass every part of GTCEU.
